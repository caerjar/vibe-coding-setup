Vibe coding setup

1. What you're installing

Vibe coding
You say what you want. An AI agent writes the code, runs it, and fixes its own errors. You look at the result and say what to change. You don't need to read the code, but you do need to check what it made.
Model
The AI itself: a large file of learned patterns that turns your words into text and code.
Agent
A program that lets a model act on your computer: create files, run commands, look at the result. It asks your permission first.
Claude Code
Anthropic's agent. It uses Claude, a hosted model, so it needs internet and a paid plan. The strongest of the tools here.
Ollama
Runs open-weights models on your own computer. Free, private, and works offline.
Qwen
A family of open-weights models from Alibaba. "Open weights" means the model file is free to download and run.
opencode
A free agent that works like Claude Code but can use a model running in Ollama.

2. Check your computer

Apple menu ▸ About This Mac. Note the chip (M1, M2… or Intel) and the memory (8 GB, 16 GB…).

Settings ▸ System ▸ About. Note the installed RAM. Windows 10 (1809 or later) or Windows 11 is needed.

Memory decides which local model you can run:

MemoryModelDownloadWhat to expect
8 GBqwen3:4b2.5 GBRuns, slowly. Fine for seeing how it works.
16 GBqwen3:4b2.5 GBUsable for small edits.
32 GB or moreqwen3-coder:30b19 GBA coding model. Noticeably better, still well behind Claude.

You also need about 10 GB of free disk (25 GB for the larger model). Claude Code itself needs only 4 GB of memory.

3. Open a terminal

A terminal is a window where you type commands instead of clicking. Every grey box on this page is a command: press Copy, paste it into the terminal, press Enter, and wait until it finishes.

Press ⌘ Space, type Terminal, press Enter.

Press the Windows key, type PowerShell, press Enter.

Prefer not to use a terminal? The Claude desktop app runs Claude Code without one. opencode and Ollama's commands still need the terminal.

4. Install Claude Code

Claude Code needs a Pro plan or higher (claude.com/pricing). The free plan doesn't include it.

curl -fsSL https://claude.ai/install.sh | bash
irm https://claude.ai/install.ps1 | iex

Optional but recommended on Windows: install Git for Windows, which gives Claude Code a better shell.

Close the terminal, open a new one, and check it:

claude --version
Worked if it prints a version number. The first time you run claude, it opens your browser to log in.

5. Install Ollama and a model

Download Ollama from ollama.com/download, open the installer, and follow it. Or install from the terminal:

curl -fsSL https://ollama.com/install.sh | sh
irm https://ollama.com/install.ps1 | iex

Download the model for your memory (see step 2):

ollama pull qwen3:4b

or, with 32 GB or more:

ollama pull qwen3-coder:30b
Important: open the Ollama app's Settings and move the context length slider to 64k. Context is how much the model can hold in mind at once. opencode needs 64k or more; with less, it fails to edit files without saying why.
ollama list
Worked if your model appears in the list.

6. Install opencode

curl -fsSL https://opencode.ai/v2/install | bash

opencode has no Windows installer command. Download the Windows zip from opencode.ai/docs, unzip it, and follow the instructions there.

opencode finds Ollama's models on its own; there is nothing to configure.

7. Your first project

Every project gets its own folder. Make one and start Claude Code in it:

mkdir my-first-project
cd my-first-project
claude

Now type in plain English. Five prompts, one at a time, waiting for each to finish:

  1. Make a single web page that shows a countdown to New Year's Eve, big and centred. Open it in my browser when done.
  2. Make the background change colour slowly through the day.
  3. Use a large serif font, and put today's date small underneath.
  4. Explain in three plain sentences what files you made and what each one does.
  5. Put this project under git and commit it with the message "first version".

Claude Code will ask before it creates files or runs commands. Read what it wants to do, then say yes. Press Esc to stop it. Press Esc twice to go back to an earlier point.

Ideas for your own: a personal page, a tracker for a habit, a recipe scaler, a small browser game, a tool that cleans up a spreadsheet you export as CSV. Start with a web page; you can see it, which makes checking easy.

8. The same, with a local model

From inside your project folder:

ollama launch opencode --model qwen3:4b

(Use the model you downloaded.) Inside opencode, /models lists the models it can use. Ask for one small change, such as Change the title to "Almost there" and make the numbers green.

Expect it to be slower and to get more wrong than Claude. Small models do well with one clear change at a time and badly with "build me an app". That trade is the point: free and private, but weaker.

10. Troubleshooting

ProblemFix
command not found after installingClose the terminal and open a new one. Still missing: run the install command again.
Claude Code says you have no accessThe free plan doesn't include it. Check your plan at claude.ai, then type /login in Claude Code.
opencode says no modelsMake sure the Ollama app is running and ollama list shows a model.
opencode chats but never changes filesContext length is below 64k. Raise it in Ollama's Settings and restart opencode.
The local model is very slowUse the smaller model, close other apps, or use Claude for this one.
The agent broke your projectIn Claude Code, press Esc twice and pick an earlier point. If you committed, ask it to "go back to the last commit".
It wants to delete or install something you don't understandSay no and ask it to explain why first.
