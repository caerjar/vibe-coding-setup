# Vibe coding setup

One static page (`index.html`): install Claude Code, Ollama, a local Qwen model and
opencode, then build a first project. No build step.

## Publish on GitHub Pages

1. Create a new public repository on GitHub (e.g. `vibe-coding-setup`).
2. Copy `index.html` and this README into it, then commit and push.
3. On GitHub: Settings ▸ Pages ▸ Source: "Deploy from a branch", branch `main`, folder `/ (root)`. Save.
4. The page appears at `https://<your-username>.github.io/vibe-coding-setup/` within a minute or two.

Commands were checked on 2026-11-11. Re-check them against the sources in the page footer
before each workshop.
